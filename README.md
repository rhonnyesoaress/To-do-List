# To-do List no terminal

Lista de tarefas simples em Python, que roda no terminal. Foi um dos meus primeiros projetos em Python (2024).

## Funcionalidades

1. Adicionar tarefas
2. Listar tarefas
3. Marcar uma tarefa como concluída
4. Sair

## Como rodar

```bash
python to_do_list.py          # versão simples
python to_do_list_colors.py   # versão com cores no terminal
```

Não precisa instalar nada além do Python 3.
